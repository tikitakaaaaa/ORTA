# ORTA MVP

Бесплатный стартовый MVP платформы ORTA.

## Что уже есть
- Главная страница
- Каталог преподавателей + поиск
- Каталог возможностей/запросов
- Демо-вход как преподаватель или школа
- Dashboard преподавателя
- Отклики на возможности
- Dashboard школы
- Создание новых запросов
- Данные сохраняются в рамках текущей сессии браузера; выбранная роль сохраняется в localStorage

## Как запустить
1. Установить Node.js 20+
2. Открыть терминал в папке проекта
3. Выполнить:

```bash
npm install
npm run dev
```

После запуска открыть адрес, который покажет Vite (обычно http://localhost:5173).
